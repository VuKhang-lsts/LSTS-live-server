Chào mừng đến với LSTS live server 🎉

LSTS live server là trình soạn thảo trực tiếp cho HTML / CSS / JS để dạy–học lập trình web tại LSTS.

  1. Gõ mã ở 3 khung HTML, CSS, JS.
  2. Bật Auto‑run để xem trước tự động hoặc bấm Run (Ctrl+Enter).
  3. Dùng Save / Load để lưu/phục hồi trong trình duyệt (localStorage).
  4. Xuất mã bằng Export .html (một file chạy độc lập) hoặc Export .css.
  5. Nhúng vào Canvas bằng thẻ <iframe> từ một đường dẫn HTTPS.

Lưu ý: Bản xem trước chạy trong sandbox; một số API hoặc truy cập liên miền có thể bị chặn. Canvas không cho nhúng trực tiếp <script> nên cần dùng iframe.
